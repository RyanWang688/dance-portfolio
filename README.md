# D.A.N.C.E. — UX/UI Case Study

Portfolio case study by **Yue Wang** for D.A.N.C.E. (Dance And Nuanced Coaching Expert), an AI motion-capture dance coaching app designed for INFO30008 Interactive Technology Project, University of Melbourne (Semester 2, 2024).

**Live site:** https://ryanwang688.github.io/dance-portfolio/

Covers stakeholder research (rich picture), design principles, wireframe-to-final iteration, the core learn / practise / upload flows, the Dance Ghost feature, usability testing findings, and my individual iteration (Offline Dance map + AI studio suggestions).

Static site: `index.html` plus WebP screens in `assets/`. No build step.
